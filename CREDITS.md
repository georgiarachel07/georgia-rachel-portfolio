# Animation inspiration

The original Canvas 2D koi animation in `koi.js` is inspired by the procedural swimming concept demonstrated in [Nagomi](https://github.com/msk1039/nagomi) by Mayank Kadam.

Nagomi is licensed under [PolyForm Noncommercial 1.0.0](https://github.com/msk1039/nagomi/blob/main/LICENSE). No source code, assets, shaders, or dependencies from that repository are distributed in this portfolio. The portfolio's fish rendering, steering, markings, water, interaction controls are independently implemented.

The four hardware and academic photographs belong to the supplied portfolio content.

## Fishing game reference

The Quiet Catch is an original Canvas 2D game using this portfolio’s existing koi renderer. The cast → bite → reel progression was informed by [Tideline by BridgeMind](https://github.com/bridge-mind/tideline), an MIT-licensed browser fishing simulator. No Tideline source code, assets, Three.js renderer, or dependencies are distributed here. The hold-to-raise fishing-bar interaction takes general inspiration from fishing minigames; no Stardew Valley assets or code are used.
